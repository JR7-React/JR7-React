## 🏆 Proyecto Destacado

<div align="center">

### 🏥 Sistema de Gestión Médica Integral (Offline-First)

[![Live Demo](https://img.shields.io/badge/🌐_Demo_en_Vivo-saludparavivir.fundesur.org-success?style=for-the-badge)](https://saludparavivir.fundesur.org/)
[![Status](https://img.shields.io/badge/Estado-En_Producción-brightgreen?style=for-the-badge)]()

</div>

**Una solución completa para centros de salud con conectividad intermitente** 🚀

Plataforma robusta diseñada para operar en entornos con acceso limitado a internet, garantizando continuidad operativa mediante una arquitectura **Offline-First** con sincronización inteligente.

### ✨ Características Principales

<table>
<tr>
<td width="50%">

#### 🔄 **Arquitectura Offline-First**
- Sincronización bidireccional IndexedDB ↔ PostgreSQL
- Optimistic UI para respuesta instantánea
- Queue de sincronización resiliente a fallos

#### 📦 **Gestión de Inventarios**
- Control de lotes y fechas de vencimiento
- Alertas automáticas de stock bajo
- Trazabilidad completa de movimientos

</td>
<td width="50%">

#### 📋 **Formatos Médicos Dinámicos**
- AIEPI (Atención Integral a la Niñez)
- Planificación Familiar
- Control Puerperal
- Wizards interactivos paso a paso

#### 📊 **Reportes Automatizados**
- Generación PDF/Excel en background
- Celery + Redis para colas asíncronas
- Dashboards estadísticos interactivos

</td>
</tr>
</table>

### 🛠️ Stack Tecnológico del Proyecto

<div align="center">

| **Capa** | **Tecnologías** |
|:--------:|:---------------:|
| **Frontend** | React 18 • Vite • Material UI v5 • Dexie.js • React Hook Form + Zod |
| **Backend** | Django • DRF • PostgreSQL • Celery • Redis |
| **Optimización** | Web Workers • react-virtuoso • Lazy Loading • ApexCharts |
| **DevOps** | Docker • Docker Compose • Railway • CI/CD |

</div>

### 🎯 Optimizaciones Clave

```javascript
// Sincronización Inteligente
✓ Reconciliación automática de IDs offline/online
✓ Detección de conectividad en tiempo real
✓ Retry automático de operaciones fallidas

// Rendimiento Frontend
✓ Virtualización de listas largas (CIE-10: +10k diagnósticos)
✓ Code Splitting y Lazy Loading estratégico
✓ Memoization para formularios complejos

// Eficiencia Backend
✓ Queries optimizadas (select_related/prefetch_related)
✓ Tareas programadas con Celery Beat
✓ Índices de base de datos optimizados
```
